# Automata-Finito-Determinista
## Requerimientos

##1. Archivos necesarios
El programa requiere los siguientes archivos ubicados en la misma carpeta:
  - AFD.py
  - Entrada.txt

El archivo entrada.txt debe contener al menos 10 Lineas. Cada linea representa una cadena que será evaluada por el AFD.

##2. Abrir la terminal

##3. Navegar hasta la carpeta del programa

Usar comandos para cambiar al directorio donde se encuentran los archivos AFD.py y Entrada.txt.

##4. Ejecutar el programa

Una vez ubicado en la carpeta correcta, ejecutar el siguiente comando:

python AFD.py Entrada.txt, El comando ejecuta el programa y utiliza el archivo Entrada.txt como entrada.

##5. Salida del programa
 
El programa mostrará el resultado en la consola. Por cada línea del archivo Entrada.txt, el programa imprimirá únicamente uno de los siguientes mensajes:
  - ACEPTA
  - NO ACEPTA

Esto indica si la cadena es aceptada o no por el autómata finito determinista.
